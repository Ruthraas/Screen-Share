# Segurança

## Reportando uma vulnerabilidade

Se você encontrou uma falha de segurança no ScreenShare (cliente desktop ou
backend), **não abra uma issue pública**. Use o
["Report a vulnerability"](https://github.com/Ruthraas/Screen-Share/security/advisories/new)
na aba Security deste repositório — cria um relatório privado, visível só
para os mantenedores, até que o problema esteja corrigido.

Inclua o máximo de detalhe possível: passos pra reproduzir, versão do app
afetada, e o impacto que você acredita que a falha tem.

## O que esperar

Respondemos o mais rápido possível. Se confirmado, corrigimos e publicamos
uma nova versão antes de qualquer divulgação pública — sem prazo fixo
prometido (é um projeto mantido por duas pessoas), mas tratado com
prioridade.

## Escopo

Cobre o código deste repositório: cliente desktop (React/Tauri/Rust) e
backend (Node/Fastify). Dependências de terceiros com vulnerabilidade
conhecida já são cobertas separadamente pelo Dependabot.
